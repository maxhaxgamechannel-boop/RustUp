# RustUP (демо)

Демонстрационный апгрейдер скинов Rust. Только виртуальная валюта UP (100 UP = $1 по цене Steam Community Market). Никаких реальных денег, депозитов, ставок и Steam-трейдинга.

## Запуск
```bash
npm install
cp .env.example .env     # впишите RUSTWIKI_API_KEY (бесплатно: https://rust.wiki/api-keys)
npm run dev              # одна команда: Vite + серверный прокси /api
npm test                 # юнит-тесты: экономика, вероятность, подбор целей, API-прокси, звук
npm run e2e              # сквозной тест в Chromium (npm i -D playwright && npx playwright install chromium)
npm run build && npm start   # продакшн: раздаёт dist/ и /api на :8787
```
Без ключа сайт работает, а каталог показывает понятное сообщение «Каталог недоступен».

## Архитектура данных
- `server/core.ts` — единственное место, где используется ключ. Прокси к `https://rust.wiki/api/v1/skins`: белый список параметров, нормализация, пропуск скинов без реальной цены, кэш 5 минут (экономит квоту), понятные ошибки (нет ключа, неверный ключ, лимит, недоступность).
- Ключ читается из `.env` (`RUSTWIKI_API_KEY`, без префикса `VITE_`), в клиентский код не попадает, `.env` в `.gitignore`.
- Клиент (`src/lib/catalog.ts`, `useCatalog.ts`) обращается только к `/api/skins` и `/api/bases`, страницы подгружаются по 48 штук («Показать ещё»), поэтому каталог масштабируется на тысячи скинов.
- Список типов предметов — `server/bases.ts` (правьте под себя).
- Инвентарь и история хранят снимок скина (itemdefid, имя, иконка, цена на момент покупки), поэтому не зависят от доступности API.

Данные и цены: [rust.wiki](https://rust.wiki) (Steam Community Market). Ссылка на rust.wiki размещена в подвале сайта по условиям API.

## Апгрейд: проценты и честная экономика
- Шанс = сумма цен вложенных скинов ÷ цена цели × 0,95 (комиссия 5%), максимум 90%. Это единственная формула (`calcChance`): ею пользуются подбор целей, экран и сам бросок.
- Кнопки **35% / 50% / 75%**: сервер (`/api/targets`) бинарным поиском по страницам `price_asc` находит реальные скины вокруг нужной цены, клиент выбирает ближайший по **фактическому** шансу и показывает отклонение от запрошенного. Если точного совпадения нет — показывается фактический процент найденного варианта.
- Цель всегда дороже вложения. Если честный шанс < 1%, цель недоступна (шанс не «подтягивается» до 1%: это давало бы положительное ожидание).
- `runUpgrade` сверяет шанс и бросок, которые вернул резолвер, с собственным расчётом; при расхождении апгрейд отменяется, предметы не списываются.
- FAST/SLOW меняют только длительность анимации.

## Магазин
Поиск, тип оружия/предмета (`server/bases.ts`), категория, сортировка (цена ↑↓, название А–Я / Я–А), чипы активных фильтров и «Сбросить фильтры». Все фильтры работают совместно, загрузка по 48 и «Показать ещё» сохранены. Я–А без поиска читается с конца каталога (страницы по 48 без пропусков). Поиск + сортировка по названию: rust.wiki при поиске отдаёт «по релевантности», поэтому сервер сортирует до 1000 совпадений сам (при превышении показывается пометка).

## Звук
Синтез Web Audio без файлов: выбор, клик, старт, прокрутка (тики + «свист»), остановка, победа, поражение, покупка/продажа, открытие/закрытие окон, ошибка. Компрессор на выходе, не более 10 одновременных голосов, защита от частых повторов. Выключатель в шапке отключает звук полностью (контекст закрывается), выбор запоминается.
